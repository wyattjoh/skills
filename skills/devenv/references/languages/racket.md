# racket

### languages.racket.enable

Whether to enable tools for Racket development.

*Type:* boolean

*Default:*

```nix
false
```

*Example:*

```nix
true
```

* <https://github.com/cachix/devenv/blob/main/src/modules/languages/racket.nix>
