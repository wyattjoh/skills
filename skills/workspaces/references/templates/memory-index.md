index is the only file loaded up front, so every entry must have a line
here. Read `MEMORY.md` and the entries touching your task before any work;
write an entry the moment an idea, rejection, surprise, or open question

become pointers. Format per entry file: a `#` title, the fact in a few
sentences, `**Why it matters:**`, and `**See:**` links.
