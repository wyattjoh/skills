# Platform Icon Sizes

Complete size tables for each platform. Use these when resizing in Phase 6.

## iOS

| Size (px) | Usage                                             |
| --------- | ------------------------------------------------- |
| 1024      | App Store                                         |
| 180       | iPhone @3x (60pt)                                 |
| 120       | iPhone @2x (60pt) / iPad @2x (60pt)               |
| 87        | iPhone @3x (29pt, Spotlight/Settings)             |
| 80        | iPad @2x (40pt, Spotlight)                        |
| 60        | iPhone @2x (20pt, Notification) / iPad @2x (29pt) |
| 40        | iPhone @2x (20pt) / iPad @1x (40pt)               |
| 29        | iPad @1x (29pt, Settings)                         |
| 20        | iPad @1x (20pt, Notification)                     |

## Android

| Size (px) | Density    | Usage                    |
| --------- | ---------- | ------------------------ |
| 512       | Play Store | Play Store listing       |
| 192       | xxxhdpi    | Launcher icon            |
| 144       | xxhdpi     | Launcher icon            |
| 96        | xhdpi      | Launcher icon            |
| 72        | hdpi       | Launcher icon            |
| 48        | mdpi       | Launcher icon (baseline) |

## macOS

| Size (px) | Usage                       |
| --------- | --------------------------- |
| 1024      | App Store                   |
| 512       | Finder @2x (256pt)          |
| 256       | Finder @1x (256pt)          |
| 128       | Dock / Finder @1x (128pt)   |
| 64        | Dock @2x (32pt)             |
| 32        | Dock @1x (32pt) / List view |
| 16        | Finder list @1x (16pt)      |

## Web / Favicon

| Size (px) | Usage                              |
| --------- | ---------------------------------- |
| 512       | PWA (manifest icon, splash screen) |
| 192       | PWA (manifest icon)                |
| 180       | Apple Touch Icon                   |
| 32        | Favicon (browser tab, standard)    |
| 16        | Favicon (browser tab, small)       |

## Raycast

| Size (px) | Usage                     |
| --------- | ------------------------- |
| 512       | Extension icon (high-res) |
| 256       | Extension icon (standard) |
